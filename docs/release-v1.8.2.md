> **关于本版本**：这个版本集中补隐私与播放体验：应用锁、隐私模式加固、简繁字幕切换与下载重命名；实时翻译的模型下载入口也已就位（模型本身尚未发布）。**在公共场合使用、或希望锁住内容的话建议更新**。下个版本希望新增或优化哪些功能？欢迎到 [Discussion](https://github.com/Amisles/Han1meAndroid/discussions) 或 [Issue](https://github.com/Amisles/Han1meAndroid/issues) 留言，你的建议会直接影响后续路线图。

## 新增 Added
- **应用锁**：设置 4 位 PIN 后，冷启动与从后台回到前台都要先解锁
- **隐私模式加固**：开启后窗口禁止截屏录屏，下载与订阅提醒通知不再显示标题 / 封面，退到后台时画面模糊并加盖遮罩（Android 12 以下改用不透明遮罩，概览缩略图不会露出内容）
- **简繁字幕切换**：播放器「更多」菜单新增「字幕」，可在简体 / 繁体间切换，只重新拉取播放与下载直链，标题、简介等详情信息保持不变
- **下载重命名**：已完成的下载可重命名，列表标题与磁盘文件名一起更新
- **实时翻译入口**：设置页仅新增「实时翻译模型」的入口，暂不支持下载。当前模型尚未发布。

## 改进 Improved
- **音量手势**：改为直接调整系统媒体音量，提示条读数取调整后的系统音量档位，与音量键及其他应用保持一致
- **切换兜底**：简繁字幕切换失败会回滚到原字幕版本并给出提示，不会停在半切换状态
- **稳定性与质量**：Lint 基线由 96 项收敛到 51 项，修掉装箱状态、KTX 调用、冗余 SDK 判断与日期格式化的 Locale 来源
- **依赖更新**：Gradle 9.9.2、AGP 9.5.2、KSP 2.3.14、jsoup 1.24.1，以及 androidx 测试与性能库

## 修复 Fixed
- **亮度残留**：退出详情页后不再残留播放器调过的屏幕亮度，系统亮度重新生效
- **推荐列表拖拽**：全屏推荐列表按住拉出条左滑现在会跟随手指拖出面板，此前只有点击才生效
