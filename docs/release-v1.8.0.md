## 新增 Added
- **播放器安全阀**：更多菜单新增睡眠定时；全屏控制栏新增播放锁与画面比例
- **方向锁定**：全屏控制栏新增方向锁按钮，把画面钉在当前横屏一侧，翻动设备不再跟着转；退出全屏自动恢复
- **首页宽屏布局**：分区改用瀑布流网格，宽屏下相邻分区并排成两栏，卡片宽度按目标列宽自适应、不再随列数缩水
- **列表位置记忆**：首页转屏或进出分屏后按分区找回原来的滚动位置
- **下载速率**：下载列表与系统通知展示实时速度与剩余时间，暂停、校验等非下载态回退到原有文案
- **连播预告**：当前集播完改为可撤销的「下一集」卡片（5 秒倒计时），没有播放列表时默认不再续播相关推荐
- **离线续播**：本地播放接入续播与观看历史，历史条目可直接进入离线播放
- **缩略图进度**：卡片缩略图底部显示观看进度条，与「继续观看」共用同一份本地进度
- **漫画阅读器**：支持双指缩放，连续模式按真实页高排版，新增阅读记录页
- **搜索筛选**：筛选条件本地保存，无结果时逐个列出可放宽的条件，点一下即可移除
- **断点续播提示**：进入播放器先提示上次看到的位置，并给出「从头看」入口
- **分享深链**：分享文本附带 hanime 深链，接收端可直接打开该视频
- **「我的」入口**：底部导航新增「我的」一级入口

## 改进 Improved
- **冷启动**：偏好存储按敏感度分层，冷启动不再等 Keystore 解密；接入 Baseline Profile 并延后非关键初始化
- **回首页**：首页快照二级缓存
- **滑动流畅度**：分区按行拆成独立 item、收敛列表页重复背景绘制、缓存卡片描述串；缩略图滚动预取，命中缓存不再渐入
- **发布时间本地化**：卡片与 banner 的发布时间按应用语言重新输出，站点返回的相对时间（如「3小時前」）不再原样出现在英文 / 日文界面
- **删除类操作**：收藏 / 历史等删除取消二次确认，即时生效并由底部提示条提供 5 秒撤销
- **下拉刷新**：订阅、收藏、历史、搜索、下载五个页面统一接入下拉刷新
- **详情页推荐**：推荐列表卡片改用与搜索页一致的列表样式

## 修复 Fixed
- **平板横屏**：恢复平板横屏适配，取消全局竖屏锁，播放页与漫画阅读器按需放开
- **下载续传**：暂停后恢复不再从块首甚至整份重下
- **下载占位图**：占位缩略图改用分辨率短文案，不再把画质全称挤成两行省略
- **站点不可达**：连接超时文案点明是站点不可达；首页加载失败的视图在重试旁给出「更换官网网址」入口，可直达设置项并自动滚动到输入框
- **下载空态**：提示横幅的占位改为按剩余空间计算，居中不再偏移
