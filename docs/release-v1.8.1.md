## 新增 Added
- **自定义播放器布局**：控件显隐与点按分区均可自定义，虚线选框配合勾选角标直接开关控件，左右点按区域宽度可用可拖拽分界独立调节
- **全屏推荐列表**：全屏右侧可拉出推荐视频，收起时露出缩略图，点击横向展开并自动隐藏控件；换片时播放器原地切换、详情页静默跟随
- **进度画面预览**：拖拽进度条时在中心时间上方显示对应画面，缩放后提供「还原画面」按钮
- **方向锁定记忆**：全屏方向锁定状态持久保存，切换视频后不再回到自动旋转
- **详情页缓存常驻**：命中缓存即用，后台静默刷新并做差异更新
- **统计入口可跳转**：「我的」页观看 / 收藏 / 下载统计可点击跳转到对应页面

## 改进 Improved
- **横屏体验**：横屏直接进入播放器全屏，页面不再整体转横
- **首屏加载**：详情页首次加载走骨架屏，不再闪现「暂无视频」占位
- **列表排版**：列表元信息按列对齐，详情页切换栏压缩并加分隔线
- **备份可靠性**：导入前整包校验，失败整包拒绝；数据库、设置与界面配置在同一事务边界内恢复，避免只恢复一部分数据
- **状态一致性**：统一下载状态跨页面的聚合口径，统一内容查询的错误结果类型与分页状态机，暂停、失败、空数据不再被混为一谈
- **稳定性与质量**：拆分播放器、下载、备份等核心模块的状态与职责，收紧模块依赖并用架构测试锁死边界

## 修复 Fixed
- **自动画质**：修正卡顿后自动降档方向反了的问题
- **网络状态**：补齐 ACCESS_NETWORK_STATE 权限声明，网络状态监听不再依赖宿主配置
- **抽屉统计**：修正侧边抽屉中的观看 / 收藏 / 下载统计不刷新的问题
